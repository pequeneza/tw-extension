## Installation
### From source (Load unpacked)
1. Clone the repo:
   ```bash
   git clone https://github.com/pequeneza/tw-extension.git
   cd tw-extension
   ```
2. (Optional) Install dependencies / build (see Development).
3. Open your browser:
   - **Chrome / Edge**: go to `chrome://extensions`
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extension folder (typically the repository root or the build output directory).
